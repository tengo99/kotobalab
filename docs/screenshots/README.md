# 공개용 스크린샷 촬영 안내

공개용 데모 화면 이미지 4장이 이 폴더에 저장되어 있으며 루트 README에 연결되어 있습니다. 아래 안내는 향후 화면을 다시 촬영하거나 교체할 때 사용합니다.

## 별도 데모 환경 실행

프로젝트 루트의 PowerShell에서 실행하세요. 실제 앱을 중단하거나 실제 DB를 변경할 필요가 없습니다.

```powershell
.\.venv\Scripts\python.exe scripts\prepare_demo.py
.\.venv\Scripts\python.exe -m streamlit run app.py --server.port 8502 -- --demo
```

<http://localhost:8502>를 열고 상단의 **공개 촬영용 데모 · 가상 데이터 · 실제 API 호출 없음** 표시를 확인하세요. 데모에서는 실제 `.env`를 읽지 않고 API 생성도 제공하지 않습니다. 문항과 검수 기록은 `data/demo/kotobalab_demo.db`에만 저장됩니다.

기존 데모 DB가 있으면 준비 스크립트가 그대로 유지합니다. 아래 번호는 처음 생성한 데모 DB 기준이며, 데모에서 추가 편집해도 실제 DB는 변경되지 않습니다.

## 화면 4장 촬영 순서

1. **01-editor-overview.png:** 편집 및 검수 탭에서 `#2 · [데모] 편집 대기`를 선택합니다. N1·N2 생성 설정, 상태별 문항 수, 문제와 선택지가 보이도록 촬영합니다.
2. **02-review-validation.png:** `#1 · [데모] 해설 누락 확인`을 선택합니다. 정답 선택지 개별 해설이 비어 있는 상태와 형식 오류 안내를 확인합니다. 필요하면 **형식 검증**을 누르세요(저장하지 않음). 검수 확인 영역도 촬영합니다. 가명은 그대로 사용하세요.
3. **03-history-comparison.png:** 수정 이력 및 검수 기록 탭에서 `#4 · [데모] AI 초안 오류 발견과 해설 수정`을 선택합니다. 최신 v3 저장 기록을 선택하고 **변경된 항목만 보기**를 체크하면 해설 누락 보완과 부정확한 단정을 문맥 중심 해설로 바꾼 전후 내용을 볼 수 있습니다. 수정 사유와 상태 변경도 함께 촬영합니다. 이 문항은 최종 검수 대기 상태입니다.
4. **04-approved-export.png:** 승인 문항 내보내기 탭에서 N2 문법 샘플 1개와 `데모 편집자`, CSV 다운로드 버튼이 보이도록 촬영합니다. 승인 기록은 가상 시연이며 실제 교재 검수 인증이 아닙니다.

이력의 최초 오류 설명은 **문제 발견 과정을 보여주기 위한 잘못된 초안**입니다. 수정 전 설명을 학습 자료로 사용하지 마세요. 데모 승인 상태는 API 자동 승인 기능을 추가한 것이 아니라 오프라인으로 구성한 촬영용 시나리오입니다.

공개용 시연에는 실제 업무 데이터가 없는 별도 실행 환경에서 샘플 문항과 가명(`데모 편집자`)을 사용하세요. 기존 실제 DB의 이름·메모를 스크린샷을 위해 수정하지 마세요. API 키가 보이는 설정 파일, 실제 이름, 개인정보가 포함된 검수 메모, 로컬 사용자 경로, 미공개 교재 내용은 포함하지 마세요.

글자가 읽히는 크기로 창을 정리하고 필요한 영역만 촬영합니다. 민감한 내용이 있으면 공개용 데이터로 다시 촬영하세요. 개인정보를 가렸다면 원본이나 편집 도구의 임시 파일을 저장소에 추가하지 마세요.
